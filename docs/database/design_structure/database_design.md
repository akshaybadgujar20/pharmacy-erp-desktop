## Structure

| File / Folder | Description |
|---------------|-------------|
| `000_database_overview.md` | Database overview, architecture, design principles, and 14 functional categories. |
| `001_table_catalog.md` | Master catalog containing all 70 tables with their purpose, module, and usage summary. |
| `tables/` | Individual documentation file for every database table. Each file contains complete technical and functional documentation for a single table. |
| `relationships.md` | Entity Relationship (ER) diagrams, foreign key relationships, dependency diagrams, and table interaction flows. |
