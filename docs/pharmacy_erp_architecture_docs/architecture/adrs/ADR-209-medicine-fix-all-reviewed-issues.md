# ADR-209: Medicine fix plan covers all reviewed issues

**Status:** Active  
**Confidence:** Explicit  
**Modules:** medicine

---

## Problem / Context

Post-implementation review found bugs across priority levels.

## Question Discussed

Which issues should the fix plan include?

## Options Considered

1. High + medium only
2. All reviewed issues
3. Bugs only skip seed cleanup

## Decision Selected

Fix all reviewed issues (high, medium, and low).

## Rationale

The historical discussion confirms the selection above, but does not explicitly record the reasoning.

## Rejected Alternatives

High + medium only; Bugs only skip seed cleanup
