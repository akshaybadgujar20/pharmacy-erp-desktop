# ADR-236: SCM fix plan includes all review items

**Status:** Active  
**Confidence:** Explicit  
**Modules:** configuration, sync, masters, settings

---

## Problem / Context

Post-implementation review found high through low issues.

## Question Discussed

Which issues should the fix plan include?

## Options Considered

1. All review items
2. High + medium only

## Decision Selected

Fix all issues from the review (high + medium + low/maintainability).

## Rationale

The historical discussion confirms the selection above, but does not explicitly record the reasoning.

## Rejected Alternatives

High + medium only — defer renames and company scoping
